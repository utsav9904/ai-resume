1. EXECUTIVE SUMMARY
================================================================================
ResumeAI is a modern web application designed to help job seekers generate ATS-optimized, 
professionally formatted resumes in minutes using artificial intelligence.

Since its initial commit on June 19, 2026, the application has evolved through 9 major 
development phases—transitioning from a minimal viable product (MVP) to a feature-packed 
resume builder featuring AI content generation, job tailoring, customizable FlowCV-style 
layouts, multi-page card previews, flexible page sizes (A4, Letter, Legal, Executive, Custom), 
dual-format export (PDF & DOCX), Firebase Auth (Google, Phone OTP, Facebook), MongoDB cloud 
persistence, EmailJS email sharing, and a unified Vercel serverless deployment.

4. KEY METRICS & FEATURE BREAKDOWN
================================================================================
- Total Commits        : 46 commits across 5 active development dates
- Primary Languages    : TypeScript, TSX, HTML, CSS
- State Management     : Zustand (`useResumeStore.ts`)
- Authentication       : Firebase Auth — Email/Password, Google SSO, Facebook Login, Phone OTP
- Cloud Database       : MongoDB Atlas via Node.js/Express REST API (Vercel Serverless)
- Offline Support      : localStorage fallback with Cloud-First sync strategy
- Key Export Formats   : PDF (jsPDF + html2canvas-pro), DOCX (`docx` library), Plain Text
- Email Sharing        : EmailJS + Firebase Storage pipeline (template_x38j328)
- Page Sizes Supported : A4 (210x297mm), US Letter (215.9x279.4mm), 
                         US Legal (215.9x355.6mm), Executive (184.15x266.7mm), 
                         Custom dimensions in millimeters
- Security Highlights  : Strict owner checks on MongoDB REST endpoints, JWT validation, 
                         Zustand store session wipes on auth transition,
                         Firebase Auth rules for Storage access control.
- Deployment           : Vercel unified deployment (React SPA + Express serverless functions)
                         Live URL: https://ai-resume-three-ecru.vercel.app/
